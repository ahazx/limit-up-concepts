# 涨停概念记忆

看代码和名字，说出它凭什么涨停。

题干是涨停的股票，选项是概念。答完之后，把你给这只票写的备注原文摊开当解析——不是背概念词，是把「这只票为什么归到这个题材」的判断依据一起记住。

**在线用 → https://ahazx.github.io/limit-up-concepts/**（手机建议「添加到主屏幕」，用起来跟 App 一样）

## 出题规则

| 情况 | 题型 |
| --- | --- |
| 这只票只挂了 1 个概念 | 单选，4 个概念里挑 1 个 |
| 挂了 2 个以上 | 多选，选出全部，选项会多一个干扰项 |

干扰项优先从「同频段」的概念里抽（不是最冷门那些），避免出现一眼就能排除的假选项。

## 功能

- **单选即判、多选提交**，选项直接标字：`✓ 正确` / `漏选` / `✕ 选错`，不只靠颜色区分
- **解析**：每个正确概念单独一块，显示你的备注全文 + 首次标记 / 最近标记 / 出现天数；没写备注的会标出来
- **范围筛选**：全部 / 今日在榜 / 3 天内新题 / 只练有备注的 / 按概念挑
- **错题本**：答错自动入库，可以只练错题；答对会自动移出
- **概念弱项**：每轮结束按累计错误数排「最该回看的概念」
- **概念速查**：90 个概念点开就是名单 + 备注，能一键「只练这个」
- **键盘**：`1-9` 选选项，`回车` 提交 / 下一题，`←→` 翻题
- **深浅两套主题**，浅色是浅蓝，深色是深蓝
- 手机 / 平板 / 桌面自适应，窄到 320px 不塌

## 题库从哪来

数据源是 Obsidian 里的 `80-交接文档/涨停概念分类.md`，由 `~/market-review/export_concepts.py` 每天 16:00 覆盖生成。构建脚本把它解析成题库：

```
275 条「股票 × 概念」关系 / 270 只股票 / 90 个概念
其中 265 只只有一个概念（出单选），5 只挂了两个（出多选）
```

**增量合并**，不是覆盖：

- 新出现的「股票 × 概念」→ 追加，打 `addedAt` 入库日，页面显示 `新题`
- 已存在的 → 更新备注 / 名称 / 在榜状态，备注变了记 `noteUpdatedAt`
- 文档里消失的 → 保留但标 `active:false`，默认不出题（设置里可以打开）

所以哪怕某天你把某个分类清空了，历史记录也不会跟着掉。

## 每天更新

```bash
cd ~/本地/zt-concept-quiz
./publish.sh        # 刷新题库 → 提交 → 推送，约 1 分钟后线上生效
```

只更新本地不发布，用 `./refresh.sh`；改了某个 md 路径用 `./refresh.sh --md 别处.md`。

想全自动（每天 16:10，接在导出之后）：

```bash
cp com.zhangxu.conceptquiz.refresh.plist ~/Library/LaunchAgents/
launchctl load ~/Library/LaunchAgents/com.zhangxu.conceptquiz.refresh.plist
```

## 本地怎么跑

直接双击 `index.html` 就能用（`file://` 也正常，题库是 `data/bank.js` 用 script 标签引入的，不走 fetch）。

想在手机上看局域网版本：

```bash
./serve.sh          # 会打印 http://<你的内网IP>:8899/ ，手机连同一个 WiFi 打开
```

## 目录

```
index.html                      # 整个页面：样式 + 逻辑，无构建、无依赖
data/bank.js                    # window.QUIZ_DATA = {...}，页面直接引
data/bank.json                  # 同一份数据的 JSON，方便脚本读
scripts/build_bank.py           # 解析 md → 增量合并 → 输出上面两个文件
refresh.sh                      # 只刷新题库
publish.sh                      # 刷新 + 提交 + 推送
serve.sh                        # 局域网预览
com.zhangxu.conceptquiz.refresh.plist   # 每天 16:10 自动发布（可选）
```

## 说明

- 题库里的「我的备注」是个人的个股归类记录，措辞口语、带缩写，**不是公司公告原文，也不构成任何投资建议**。
- 学习记录（正确率 / 错题本 / 概念统计）存在浏览器 `localStorage`，**换设备不同步**，清缓存会清掉。
- 单选题是「四选一」，多选只有 5 道——不是写漏了，是数据里本来就只有 5 只票挂了两个概念。
